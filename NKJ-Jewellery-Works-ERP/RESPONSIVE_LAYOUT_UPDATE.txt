API routing correction:
- Backend default port: 8086.
- Vite /api proxy default target: http://localhost:8086.
- If you intentionally run the backend on another port, set VITE_BACKEND_TARGET before starting Vite, or update the Vite config target to match.
- Local CORS patterns allow localhost and 127.0.0.1 development ports. For deployment, replace CORS_ALLOWED_ORIGINS with the exact trusted frontend origin(s).
